Example

Offset difference = 3.4 − 1.6 = 1.8 m
Fall = 1.8 × 2.5% = 0.045 m
Answer: 12.329 − 0.045 = 12.284 m

Subgrade / GSB Peg Level

Manual Chainage • Multiple Offset • PCL RL, Camber, Depth और HI से result

Example
Chainage 37+200 • PCL RL 12.500 • Offsets 2, 4, 6 • Camber -2.5% • Depth 150 mm • HI 14.000
Peg RL: 2m = 12.300, 4m = 12.250, 6m = 12.200
Staff: 1.700, 1.750, 1.800
Offsets: हमेशा multiple हैं। ऐसे डालें: 2, 4, 6. Same Offsets बंद करने पर हर chainage में अलग offset list डाल सकते हैं।
ChainagePCL RLOffset(s)HIPeg RLStaff ReadingChainage
Formula: Peg RL = PCL RL + (Offset × Camber ÷ 100) − Depth(m)
Staff Reading = HI − Peg RL
Chainage और PCL RL अलग-अलग column हैं।
Chainage: हर row में Chainage manual डालें। Chainage box पर tap करते ही number keypad खुलेगा, जिसमें + key भी रहेगी। जैसे 37+200।
Depth: ऊपर set किया गया Depth सभी rows में same रहेगा।
HI: केवल जहाँ HI बदलती है वहीं नई HI डालें; बाकी rows में पिछली HI अपने-आप use होगी।
पहली Chainage, PCL RL और HI डालते ही result automatic आएगा.
